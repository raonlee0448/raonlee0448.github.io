One-time setup · no token paste

Set up sign-in

This creates a private GitHub App that can only write images to your website repo. You click through GitHub’s own screen. Nothing is submitted until you press the button, and the app is not created just by opening this page.

The login helper is already on your Cloudflare Worker. You only need to create and install the GitHub App with the button below. No token paste, and no code to edit.

What you will do, once

  1. Press Create the uploader app. GitHub will ask you to confirm the name and permissions (Contents write, metadata read, Pages read).
  2. When GitHub sends you back here, wait a moment. Then press Install on my website repo and choose only raonlee0448/raonlee0448.github.io.
  3. Open the uploader and press Sign in with GitHub.
Back to the uploader

The form posts only when you press that button. After GitHub sends you back here, this page finishes setup automatically. The app secret stays in the Worker and is never written to your website files.
